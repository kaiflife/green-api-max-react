# МАКС Мессенджер Веб-Клиент (Тестовое задание GREEN-API)

Минималистичный интерфейс для интеграции с **MAX API от GREEN-API**. Проект реализован на **React** с соблюдением принципов компонентного подхода и разделения бизнес-логики.

## 🚀 Стек технологий

- **Компилятор / Сборщик:** Vite + React (JavaScript)
- **Линтер:** ESLint
- **Стилизация:** Чистый CSS (Кастомный UI под фирменный стиль корпоративного мессенджера МАКС)

## 📁 Архитектура проекта

- `src/services/greenApi.js` — Изолированный слой для сетевых запросов (методы `SendMessage`, `ReceiveNotification`, `DeleteNotification`, `CheckAccount`).
- `src/hooks/useChatPolling.js` — Кастомный хук для реализации бесконечного цикла фонового опроса сервера (HTTP API Long Polling).
- `src/components/` — Разделенные визуальные компоненты (`Sidebar`, `MessageList`, `MessageForm`).

## 🛠 Локальный запуск

1. Склонируйте репозиторий и перейдите в папку проекта:

```bash
cd green-api-chat
```

2. Установите все необходимые зависимости:

```bash
npm install
```

3. Запустите локальный сервер разработки:

```bash
npm run dev
```

4. Откройте приложение в браузере по адресу `http://localhost:5173`.

## ⚙️ Особенности работы в тестовом инстансе МАКС

В приложении реализован метод проверки аккаунта `CheckAccount`. Обратите внимание: на тарифах разработчика внешние телефонные номера могут отсутствовать в изолированной базе данных инстанса. Для удобства тестирования приложение автоматически переключается на отправку сообщений по прямому `phoneNumber`, если числовой `chatId` не был сгенерирован сервером.
